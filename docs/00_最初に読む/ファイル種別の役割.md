# ファイル種別の役割

## この文書の位置づけ

この文書は横断ガイドです。
個別ファイルの関数一覧や詳細仕様の正本ではありません。

目的は、`main/modules/*/internal/*.ps1` や `main/dom/features/**/*.js` を開く前に、ファイル名から責務を推測できるようにすることです。
詳細は各ファイル別ドキュメントを参照してください。

## まず理解すること

このプロジェクトでは、ファイル名は責務境界を表します。
最初から関数の中身を全部読むのではなく、次の分類で読むと迷いにくくなります。

| 種別 | 主な役割 | 詳細の正本 |
|---|---|---|
| `*.psm1` | module loader / 公開関数の入口 | 対応する `*.psm1.md` |
| `Runner.ps1` | Jobの外枠。Context、設定、依存解決、Workflow呼び出し | `internal__Runner.ps1.md` |
| `Workflow*.ps1` | 処理順序、状態遷移、結果集約 | 対応する `internal__Workflow*.ps1.md` |
| `Rules.ps1` / `Reconciliation.ps1` | 業務判定、突き合わせ、抽出条件 | 対応する個別ドキュメント |
| `Dependencies.ps1` | 依存ポートの構築・検証・テスト差し替え境界 | `internal__Dependencies.ps1.md` |
| `DomAdapter.ps1` | Workflowから見た業務名のDOM操作窓口 | `internal__DomAdapter.ps1.md` |
| `DomOperations.ps1` | DOM helper operation registry と呼び出し境界 | `internal__DomOperations.ps1.md` |
| `Output.ps1` | CSVなどの出力境界 | `internal__Output.ps1.md` |
| `Models.ps1` | データ構造・正規化された行構造 | 対応する個別ドキュメント |
| `dom/features/**/*.js` | ブラウザ内で実行されるDOM helper | `docs/08_DOM_JavaScript/**` |

## 読む順番

初めて読む場合は、次の順番で十分です。

1. `docs/00_最初に読む/01_全体像.md`
2. `docs/00_最初に読む/03_JobNameとContextの関係.md`
3. この文書
4. 対象ジョブの「読み方」文書
5. 対象ジョブの `Runner.ps1` → `Workflow*.ps1` → 個別部品

## 誤解しやすい点

- `.psm1` は処理本体ではありません。内部ファイルを読み込み、公開関数を外へ出す薄い入口です。
- `Workflow*.ps1` は処理順序を書く場所です。CSVの細かい判定やDOM selectorを持たせないでください。
- `Dependencies.ps1` は複数の依存を束ねますが、業務判断やDOM selectorを置く場所ではありません。
- `DomAdapter.ps1` と `DomOperations.ps1` は似ていますが、前者は業務名、後者はDOM helper operationの境界です。
- 統合版ドキュメントにない詳細は欠落ではなく、個別ファイルドキュメントを正本にしています。

## この文書を更新する条件

この文書を更新するのは、ファイル種別の読み方、責務分類、誤解しやすい点が変わった場合です。
個別関数の追加・削除だけなら、対応する個別ファイルドキュメントを更新してください。
