# 変更時のテスト逆引き

## 1. このドキュメントの使い方

ファイルを変更したときに、最初に確認すべきテストを逆引きする。

ここでいう「確認」とは、単に実行するだけではなく、テスト名を読んで、どの仕様を守っているか理解することを含む。

## 2. 起動設定・Foundation起動周辺を変更した場合

対象例:

```text
run_job.ps1
config/foundation.jobs.psd1
config/foundation.config.psd1
modules/Foundation/internal/Bootstrap.ps1
modules/Foundation/internal/Config.ps1
modules/Foundation/internal/JobRegistry.ps1
modules/Foundation/internal/RunContext.ps1
```

確認するテスト:

```text
Foundation.Entrypoint.Tests.ps1
Foundation.Config.Tests.ps1
Foundation.JobRegistry.Tests.ps1
Foundation.JobRegistry.UsesDom.Tests.ps1
Foundation.RunContext.Tests.ps1
Foundation.PublicApi.Tests.ps1
```

特に見るべき観点:

```text
JobNameから正しいJobDefinitionを取得できるか
ModulePath / CommandName が正しく解決されるか
ContextにJobDefinitionとJobSettingsの両方が入るか
DOMあり/なしジョブの扱いが壊れていないか
```
